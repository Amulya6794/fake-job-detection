## Fake Job Detection Using NLP and Machine Learning

 ## Overview

This project detects fraudulent job postings using Natural Language Processing (NLP) and Machine Learning.

## Features

* Text preprocessing
* TF-IDF vectorization
* Logistic Regression classifier
* Streamlit web application
* Real-time prediction

## Dataset

Fake Job Postings Dataset containing 17,880 job listings.

## Technologies Used

* Python
* Pandas
* Scikit-learn
* NLP
* Streamlit

## Results

Achieved approximately 97% accuracy in detecting fake job postings.

## How to Run

```bash
streamlit run app.py
```
